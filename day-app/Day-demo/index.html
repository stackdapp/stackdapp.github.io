Welcome to Stackd Day
Help your kid manage their day with schedules, tasks, timers, and XP rewards — all in one place.
Free to start. Upgrade to Pro for $2.99 — one-time, no subscription.
⚙️
Set up as a parent first
Tap the Parent button in the top right to set your kid's name, build their schedule, and add tasks.
The parent tab is open by default. Set a PIN in Parent → Settings to lock it from your kids.
🗓
Build your kid's day
Go to Parent → Schedule to add blocks like "Wake Up", "School", or "Free Time". Each block has a time and XP value.
Free plan includes 3 schedule blocks and 3 tasks. Upgrade to Pro for $2.99 — one-time — for unlimited blocks, rewards, themes, and more.
⭐
XP and rewards
Kids earn XP by completing tasks and blocks. With Pro they can spend it in the Rewards tab on things you set up — like screen time or choosing dinner.
Rewards, streaks, themes, and the daily report are all Pro features. Upgrade once for $2.99.
🚀
You're ready to go
Hand the phone to your kid and walk through the first day together. The routine builds fast once they see the XP adding up.
Revisit this guide anytime from Parent → Settings.
