What it does

Stackd Day

A daily routine tracker. Parents build a schedule and task list. Kids earn XP by working through the day and checking off tasks.

Parent setup

Set it up before handing it over

Tap Parent in the top-right corner to get started.

  1. 1

    Set your kid's name

    Parent → Settings. Their name shows up in greetings throughout the app.

  2. 2

    Build the schedule

    Parent → Schedule. Add blocks for the main parts of the day — Wake Up, Breakfast, Free Time, Bedtime. Each block gets a start time and XP value. Free plan supports up to 3 blocks.

  3. 3

    Add daily tasks

    Parent → Tasks. Add chores and habits — "Make bed", "Brush teeth", "Feed the dog". Each earns XP when checked off. Free plan supports up to 3 tasks.

  4. 4

    Save your changes

    Tap Save Changes at the top of the parent area. Nothing saves until you do.

How kids use it

Walk through day one together

Sit with your kid the first time. Once they see XP go up, they get it immediately.

  • 🏠

    Home

    Current block, XP today, level, and streak. The big number is their score.

  • 🗓

    Day tab

    Full schedule for the day. Current block is highlighted. Tap to mark blocks complete.

  • ✅

    Tasks tab

    Tap a task to check it off and earn XP. Unchecking is allowed — accidents happen.

Common questions

Stackd Day FAQ

Does XP reset every day?
Daily XP resets at midnight — think of it as a daily score. Total XP (used for leveling and rewards) carries over and never resets.
Does it work offline?
Yes. Once installed, Stackd Day works fully offline. All data stays on the device.
Will I lose data if I uninstall?
Yes. Before uninstalling, go to Parent → Settings → Download Backup. You can restore it after reinstalling from the same screen.
Is there a subscription or recurring charge?
No. Stackd Day Pro is a one-time $2.99 purchase. Pay once and it's yours forever — no monthly fees, no subscriptions.
