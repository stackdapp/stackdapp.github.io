Quick Start Guide

Get started with Stackd School

Run homeschool sessions with subject timers. Kids earn XP by completing each subject and finishing daily habits.

What it does

Stackd School

A homeschool session tracker. Parents set up subjects and time goals. Kids start a session, work through each subject with a countdown timer, and earn XP for finishing.

Parent setup

Set it up before handing it over

Tap Parent in the top-right corner to get started.

  1. 1

    Set your kid's name

    Parent → Settings. Their name shows in greetings throughout the app.

  2. 2

    Add subjects

    Parent → Subjects. Add what your kid studies — Math, Reading, Science, etc. Set a session length and XP value for each. Free plan supports up to 3 subjects.

    Tip: 15–20 minutes per subject is plenty for most kids. Shorter sessions = more wins.
  3. 3

    Add daily tasks (optional)

    Parent → Tasks. Add school habits like "Read independently" or "Review flashcards". These earn bonus XP. Free plan supports up to 3 tasks.

  4. 4

    Save your changes

    Tap Save Changes at the top of the parent area. Nothing saves until you do.

Common questions

Stackd School FAQ

What happens when the timer runs out?
A warning shows at 2 minutes remaining. When it hits zero the subject ends, but kids can still mark it complete and earn XP. The timer is a guide, not a hard cutoff.
Can subjects be done in any order?
Yes. Subjects are listed in the order you added them, but your kid can tap any subject to start it. No forced order.
Does it work offline?
Yes. Once installed, Stackd School works fully offline. All data stays on the device.
Will I lose data if I uninstall?
Yes. Before uninstalling, go to Parent → Settings → Download Backup. You can restore it after reinstalling from the same screen.
Can I use both Stackd Day and Stackd School?
Yes. They're separate apps that work great together. Use Day for the daily routine and School for homeschool sessions.
Can I cancel Pro anytime?
Yes. Cancel through your Google Play account anytime. You keep Pro access until the end of your billing period.
